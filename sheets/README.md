# قالب Google Sheets المقترح

أنشئ Spreadsheet باسم **Media Academy Database**، ثم استورد كل CSV في ورقة تحمل الاسم نفسه. الصف الأول هو عناوين الأعمدة. استخدم IDs ثابتة وفريدة، وتواريخ بصيغة ISO مثل 2026-11-07.

| الورقة | الغرض |
|---|---|
| Students | حسابات وبيانات الطلاب |
| Admins | حسابات الإدارة |
| Courses | المواد الدراسية |
| Materials | الكتب والملفات وروابطها |
| Lectures | المحاضرات والجداول |
| Exams | الاختبارات |
| Results | درجات الطلاب لكل اختبار |
| Attendance | سجل الحضور |
| Announcements | الإعلانات |
| Complaints | الشكاوى والمقترحات |
| Settings | إعدادات النطاق وموقع الحضور |

اربط السجلات باستخدام student_id وcourse_id وlecture_id وexam_id. لا تخزن كلمات المرور كنص صريح في الاستخدام الفعلي؛ خزّن hash مع salt وتحقق منها داخل Apps Script. صلاحيات الإدارة يجب التحقق منها على الخادم في كل طلب.
