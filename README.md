# Media Academy

واجهة عربية RTL لمنصة أكاديمية، منشورة عبر GitHub Pages.

## التشغيل
- افتح رابط GitHub Pages بعد اكتمال نشر Actions.
- اختر دخول الطالب أو دخول الإدارة من نفس الصفحة.
- نسخة الواجهة الحالية تعمل محلياً باستخدام LocalStorage ولا تتصل بأي خدمة سحابية بعد.

## حسابات العرض التجريبي
- الإدارة: `admin` / `admin123`
- الطالب: `S001` / `1234`

**تنبيه أمني:** هذه بيانات تجريبية فقط. تسجيل الدخول والتخزين المحلي ليسا آمنين للاستخدام الحقيقي أو للنشر العام. لا تضع بيانات طلاب حقيقية قبل ربط Google Sheets / Apps Script وإضافة التحقق والصلاحيات من جهة الخادم.

## ملفات المشروع
- `index.html`: الموقع كامل كواجهة أمامية مستقلة.
- `sheets/`: قوالب CSV لأوراق Google Sheets المقترحة، مع ملف يشرح الأعمدة والعلاقات.
- `.github/workflows/deploy-pages.yml`: نشر GitHub Pages.
- `.github/workflows/verify.yml`: فحص بناء بسيط.

## ربط Google Sheets لاحقاً
أنشئ Google Spreadsheet، واستورد كل ملف CSV في ورقة منفصلة بالاسم الموضح في `sheets/README.md`. اكتب Apps Script كواجهة API، واجعل التحقق من كلمات المرور والصلاحيات على الخادم، ولا تستخدم كلمات مرور صريحة في Sheets في الإنتاج.
