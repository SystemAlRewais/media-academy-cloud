# Media Academy Cloud

منصة إدارة أكاديمية عربية متعددة المؤسسات، واجهتها React + Vite، وقاعدة بياناتها المخططة Google Sheets من خلال Google Apps Script.

## ما يحتويه المشروع

- بوابة الطالب: الملف الجامعي، كود الطالب، السجل الانضباطي، المحتوى، الحضور، الإعلانات، الشكاوى.
- المنتدى الطلابي: منتدى عام ومساحات لكل فرقة، مواضيع وردود.
- مركز الإدارة: تسجيل دخول إداري، لوحة مؤشرات، عرض الطلاب والفرق والمحتوى والحضور والسجل والانضباط والإعلانات والمنتدى والتذاكر.
- تصميم RTL متجاوب للموبايل والكمبيوتر.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## ربط Google Sheets

1. أنشئ Google Sheet خاصاً (Private).
2. افتح Apps Script وأنشئ مشروعاً.
3. انسخ `backend/Code.gs` إلى ملف `Code.gs` في مشروع Apps Script.
4. انقل إعدادات `backend/appsscript.json` إلى ملف manifest في Apps Script.
5. في Script Properties أضف `SPREADSHEET_ID`, `BOOTSTRAP_EMAIL`, `BOOTSTRAP_PASSWORD` (كلمة مرور مؤقتة قوية 12 حرفاً على الأقل).
6. شغّل `setupInitialOwner()` مرة واحدة. ينشئ التبويبات ويجهز أول حساب مالك، ثم يحذف خاصية كلمة المرور المؤقتة.
7. انشر Apps Script كـ Web App بعد مراجعة صلاحيات الوصول، وانسخ رابط `/exec`.
8. ضع الرابط في `src/config.js` في `appsScriptUrl`.

التفاصيل في `backend/README.md`.

## تنبيهات مهمة قبل الإنتاج

- لم يتم نشر المنصة أو تفعيل رابط Apps Script.
- لم يتم إنشاء Google Sheet أو إدخال بيانات طلاب حقيقية بعد.
- واجهة الطالب الحالية ما زالت تحتوي بيانات عرض تجريبية في بعض الشاشات؛ لا تعتمد عليها كسجلات فعلية قبل توصيل خدمات الطالب والتحقق من الصلاحيات.
- شاشة الإدارة تتطلب API فعالاً وحساباً تم إنشاؤه بواسطة `setupInitialOwner()`.
- Google Sheets مصدر البيانات الإداري. المنتدى في هذه النسخة يستخدم تحديثاً دورياً (Polling) عند توصيله؛ ليس WebSocket أو Push فورياً. للمحادثات الفورية ذات الحمل الكبير نوصي بإضافة Firebase أو Supabase Realtime مع إبقاء Sheets للتقارير والسجلات.
- لا تضع كلمات مرور أو مفاتيح أو بيانات طلاب حقيقية في GitHub. اجعل الشيت خاصاً، واحفظ ملفات الطلاب في Drive بصلاحيات محددة.
- يجب اختبار الصلاحيات، الدخول، التسجيل الجغرافي، التزامن، النسخ الاحتياطي، واستعادة الحساب قبل النشر العام.

## الحالة

مرحلة بناء الواجهة وأساس خادم Apps Script. لم يتم النشر.
