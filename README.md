# Media Academy Cloud

واجهة منصة أكاديمية متعددة المؤسسات باللغة العربية (RTL)، مبنية باستخدام React وVite.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## الوحدات الموجودة في الواجهة

- بوابة الطالب والملف الجامعي المرتبط بكود الطالب.
- السجل الجامعي والانضباطي: تنبيهات، مخالفات، إجراءات، وسجل زمني.
- منتدى عام ومنتديات منفصلة لكل فرقة، مع واجهة نشر ومناقشة.
- المحتوى الدراسي والحضور والإعلانات والدعم.
- تصميم متجاوب للموبايل وسطح المكتب.

## ملاحظات الربط والتشغيل

- البيانات الظاهرة حالياً بيانات عرض تجريبي وليست سجلات طلاب حقيقية.
- لم يتم نشر الموقع، ولم يتم تفعيل أي خدمة استضافة.
- لم يتم ربط Google Sheets أو Google Apps Script بعد.
- إعداد رابط Apps Script موجود في `src/config.js` ويظل فارغاً حتى يقدّم المالك رابط النشر الصحيح.
- المنتدى يعرض تجربة واجهة فقط. تشغيله كمنتدى حي بين الطلاب يتطلب backend موثوقاً مع اشتراكات لحظية (Realtime) مثل Firebase أو Supabase، مع قواعد صلاحيات تمنع تسريب بيانات الفرق.
- لا تُخزّن بيانات حساسة أو كلمات مرور في الواجهة أو مستودع GitHub.
- يجب أن تتحقق الخوادم من هوية الطالب وصلاحياته، وتوثّق مصدر وتاريخ أي مخالفة أو قرار. يجب أن تكون تفاصيل الانضباط مرئية فقط للطالب المعني والإدارة المخولة.
- لا يُطلب موقع الطالب إلا عند بدء تسجيل الحضور وبموافقته، ويجب التحقق من النطاق الجغرافي على الخادم.

## الحالة

واجهة أولية قابلة للتطوير. لم يتم النشر أو ربط قاعدة البيانات حتى الآن.
